# 対象指定による能力実効値の適用・交換

## skill.csvへの設定例

swap_defensesは、指定された対象だけのPD・SDを、もう一方の個体の実効値にする。

| 用途 | effect1 | effect_target1 | effect_chance1 | effect2 | effect_target2 | effect_chance2 |
|---|---|---|---|---|---|---|
| 自分だけを相手と同じ値にする | swap_defenses | self | 100 | none | enemy | 0 |
| 相手だけを自分と同じ値にする | swap_defenses | enemy | 100 | none | enemy | 0 |
| 自分と相手の値を交換する | swap_defenses | enemy | 100 | swap_defenses | self | 100 |

category=status、attack_type=none、power=0。EN費用・優先度・技名は技CSVで設定する。effect2・effect3にも同じ効果を設定可能。既存の正式技には今回割り当てていない。

| effect.csvの列 | 設定 |
|---|---|
| effect_id | swap_defenses |
| name | 防御交換 |
| effect_group | stat_exchange |
| damage_type | none |
| damage_value | 0（倍率ではない） |
| turn | 0（ターン期限なし） |
| can_move | TRUE |
| target_stat | phy_def\|sp_def |

## 確定した動作

- コピー元は能力ランク・状態異常・パッシブを含む、技の追加効果処理開始前の整数実効値。技の全ての交換枠で同じ値を参照する。
- selfは自分だけ、enemyは相手だけを変更する。両方の枠を設定するとPD同士・SD同士の交換になる。先に変更した側の値を後の枠へ流用しない。効果欄の順序を逆にしても交換結果は同じ。
- 同じ対象に複数枠を設定しても、同一技内で値が往復したり累積したりしない。再使用時には、その時点の値を新しく保存して適用する。
- 各枠のeffect_chanceを個別に判定する。片側だけ成功すれば、その対象だけが変化する。相手の変化技無効はenemy枠を防ぐが、self枠は自分への効果として適用する。
- HP・EN・他の能力・能力ランクそのものは交換しない。正式マスタを変更せず、個体のstatExchangeに一時補正を保持する。
- 交換後も新たな能力ランク・状態異常・パッシブ条件変化に応じて変動する。
- 通常交代・特殊交代・戦闘不能で、その個体の補正を解除する。もう片方の個体に残った補正は維持する。パワーリレーの対象外。芭蕉扇のフィールド解除でも消えない。

各対象の能力について、受け取る値と適用時点の「交換補正を除いた実効値」を保存する。その後は通常の能力計算結果×受け取った値÷保存した実効値を切り捨て、最低1とする。既存補正を二重適用しない。

対象能力はtarget_statを半角パイプで区切り、PA・PD・SA・SD・SPから指定できる共通処理。未知の能力・HP・重複能力・持続ターン付きの定義は非対応として診断する。技のeffect_targetはselfまたはenemy、分類は変化技に限る。bothは使用せず、2枠で双方を指定する。

付与確率・眠り・EN不足・相手の変化技無効・隠れ状態は既存の対象別共通判定に従う。デコイ越しの変化技は既存どおり作用する。コピー元の相手が戦闘不能ならself枠も適用しない。乱数は既存の追加効果確率判定だけを使用する。

へんしんは基礎能力とランクをコピーする既存仕様を維持し、相手の交換補正自体はコピーしない。自分に付与済みの交換補正は個体効果として維持し、交代・戦闘不能で消える。

## 接続箇所

- battle-core.js：effectKind、statExchangeSnapshot、previewStatExchange、effectiveStat、共通効果適用、交代・戦闘不能処理。
- battle-ai.js：対象別の適用後盤面を共通計算で評価。同じ技の複数枠は同じコピー元を参照し、同一対象の重複を二重評価しない。確率付き効果の評価は既存の確率加重方式。
- go-ui.js / app.js：再生フレームに補正を保持し、能力値・状態ラベル・対象別ログへ反映。表示配置・配色の変更なし。
- GO_Editor.html：効果グループ・対象能力の選択、検証、CSV保存・再読み込み。self/enemy指定は既存の対象欄を使用。
- index.html：スクリプトのキャッシュキーを更新。バージョン番号は変更しない。
- test/stat-exchange.test.mjs / test/editor.test.mjs：片側適用・双方交換・順序・重複・確率・解除・各補正・予測・AI・GOE往復を検証。
