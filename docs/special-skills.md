# v0.32 特殊技と威力変動

仕様の採用順はGO確定仕様、正式CSV・技説明、MHB既存実装、暫定案。MHBのコードと参照CSVを読み取り専用で調査し、移植できる部分を geneOrderBattle に接続した。

| 機能 | MHBの根拠とGOでの処理 |

## 暫定の優先順

- 属性無効・位置・回避を先に判定し、その後に水吸収、特殊反射、通常ダメージと反撃を処理する。同一対象の個体ガードは最も強い軽減を使う。水の変化技で吸収は発動しない。満タン時も0ダメージ。吸収・反射で敵への追加効果は成立せず、同一行動の自己効果は生存中に処理する。
- 反射は各種軽減を適用した仮想ダメージで1回計算し、返すHPダメージは再帰的な反撃・反射の対象にしない。反撃・反射で使用者が倒れた時は残りの技効果を停止する。直接攻撃と反動で両者が倒れた場合は双方の控えを確認してから勝敗・引き分けを判定する。
- 溜め技は予約時に次回威力強化を適用・消費し、解放時は予約済みの威力を使う。位置中の例外命中や充填解除は今後の技定義に応じて確認する。

## 次の属性攻撃の威力強化

- battle_effect.csv の next_element_power は element に正式属性ID、modifier に威力倍率を指定する。無属性は none。旧 bf_next_fire_power_150 も同じ効果グループで動く。発電（skill_020）は雷、EN消費0、自己SD＋2、雷攻撃の1.5倍強化を100％で付与する。
- 属性ごとに一つだけ保持し、再付与で上書き。別属性の強化は共存する。ターン経過・別属性の攻撃・変化技・回避で消えず、交代・戦闘不能で解除する。パワーリレーでは引き継がない。
- 物理・特殊を問わず、対象属性の攻撃を実行した時点で消費する。回避・無効でも消費し、EN不足や行動前の戦闘不能で未実行なら発動しない。可変威力・パッシブと倍率を掛け、既存の四捨五入・上限を適用する。ログに付与と消費を表示し、戦闘詳細で保持中の属性と倍率を確認できる。
- AIとプレビューは戦闘と同じ威力計算を読み取り専用で利用する。AIは次の攻撃の見込み増分を評価し、同等以下の強化を重ねること自体には加点しない。

## 確認待ち

- 猪突猛進の暫定表はEN0〜7で威力 **130・130・130・130・143・156・169・195**。MHBのEN3〜7行を移植し、EN0〜2はMHBの未一致時の1倍。上限200は正式CSVどおり。EN7で200に達するように調整するかは別途確認する。

## CSVの調整

- 発生率は skill.csv、継続割合・回復量・反動割合は effect.csv、持続・軽減・反撃倍率・特殊効果の対象属性と補正は battle_effect.csv、威力倍率は power_rule.csv を参照する。パッシブは今後 passive.csv を効果量の正本とする。
- battle_effect.csv の element は水吸収・相性置換の対象属性。modifier は吸収の最大HP百分率、置換する相性倍率、guard_break が残す軽減率の割合を効果種別ごとに表す。
- 溜め、姿消し、個別相性、被弾時威力は現行技の確定メカニクスとして選択可否で検査する。通常効果の付与率などはCSVの確率を使用する。
- CSVを保存して画面を再読込し、新しい対戦を開始すると反映される。テストでは正式ファイルを書き換えず、CSVレスポンスのテスト用差分をローダーに渡して検証する。

## MHBから追加で流用した仕様

- 鎌鼬とクイックブレイブは行動時点の実効敏捷の比（自分 ÷ 相手 × 100）を使用。境界は100・150・200・300%、威力は順に30・60・72・78・90。ランク、パッシブ、場の補正を適用し、倍率は power_rule.csv を参照する。
- 炎の風は effect.csv の火やられを付与する。最大体力の15%をターン終了時に5回。再付与で持続を更新し、控えでは停止。毒とは共存する。
