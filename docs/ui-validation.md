# v0.60 UI検証

リポジトリのルートで `node --test` を実行する。Edgeでの画面テストは `node tools/check-ui.cjs`。Playwrightが別の環境にある場合は `GO_PLAYWRIGHT_PATH` にそのモジュールパスを設定する。テストはループバックHTTPを使い、スクリーンショットを `.cache/v0.60-edge/` に保存する。

- 既存133件と追加4件の計137件が成功。正式編成の検証、プレイヤー対AI、デコイ・パワーリレー、羽音、毒、戦闘不能・補充・再戦、フレーム記録、旧状態・保存領域の非使用を確認した。
- 旧ランダム同士1,024戦、AI同士1,024戦、AI対ランダム256戦、旧長期戦9編成、同一32編成の6タイプ比較が回帰テストで成功。上限到達は従来の検証値と同じ。
- Edgeの幅1280pxと390pxでタイトル、編成、先発設定、技選択、EN不足と未完成技の無効化、共通回避、通常交代、デコイとリレー、羽音、毒、戦闘不能・補充、勝敗・再戦を確認。手動対AIとAI対AI、ダブルクリック、溜め解放の既存アニメーション、演出中の離脱、BGMの開始と停止、デバッグへの遷移も確認した。
- 各幅でタイトル、編成、戦闘、特殊交代、図鑑、勝敗を保存した。JavaScript例外・横スクロール・旧 `assets/` へのリクエスト・localStorage操作は0。既知の不足画像 `character_047.png` と `character_064.png` の確認リクエストは404で、画面は代替表示した。

MHB由来のCSS、テンプレート、ゲージ、ボタン、戦闘の背景とモーションレイヤーを使った。GO画像の原寸は表示枠に収まらないため、PC・モバイルで表示サイズを制限した。タイトルはGO専用素材を待つ間、文字を使用する。
