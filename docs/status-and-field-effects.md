# v0.31 状態異常・継続ダメージ・フィールド効果

## 現行の状態異常仕様（2026-11-20）

編集済みのeffect.csvを正本とする。毒の期間はユーザー確認により5ターンを維持する。以下のv0.31比較表は移植時の履歴であり、毒・火やられの現行性能はこの節を優先する。正式CSV・キャラクター・パッシブ・技の割り当ては本実装では変更していない。

| ID | 継続HPダメージ | 持続 | 能力補正 | 行動不能確率 |
|---|---|---|---|---|
| poison | 最大HPの10% | 5ターン | なし | 0% |
| burn | 最大HPの5% | 5ターン | 物理攻撃×0.5 | 0% |
| paralysis | なし | 5ターン | 敏捷×0.5 | 25% |
| frostbite | 最大HPの5% | 5ターン | 特殊攻撃×0.5 | 0% |

能力補正は基礎値・能力ランクを変更せず、ランク・パッシブ・フィールドと独立して乗算する。補正を含む計算の最後に切り捨て、最低1を維持する。既存の補正がない場合の端数処理は維持する。同じ効果IDは1件で、再付与では残りターンと定義値の大きい方へ更新する。異なる状態異常は共存する。付与ターン末から残りターンを消費し、通常交代では保持して控えでのダメージ・ターン消費を停止する。継続ダメージはMHB準拠の四捨五入・最低1。HPダメージなしのstatus行は0ダメージの通知を出さず期間だけ消費する。状態解除・期限満了で能力補正と行動不能確率も消失する。

技実行直前、EN・HP費用・特殊交代の選択待ち・威力強化消費より前に、既存のbattle.randomで行動不能を判定する。失敗時は技と追加効果を実行せず、技使用回数・パッシブ使用回数も増えない。通常交代・待機は判定しない。共通回避や特殊交代は技なので判定対象。溜め開始・解放も各実行時に判定し、失敗した解放は予約と確定威力を保持する。失敗しても場の状態異常の期限・継続ダメージ・自然回復・EN回復は通常どおり進む。

AIとプレビューは共通のeffectiveStat/effectiveSpeedを使う。previewDamageのdamage・HPは技を実行できた場合の条件付き結果を維持し、actionFailureChance、executionChance、expectedDamage、expectedDecoyDamage、expectedHpCostを別途返す。AIは実行確率を期待ダメージ・戦闘不能の確度・技の期待価値に反映し、HPダメージのない麻痺も能力補正と行動不能の価値から評価する。予測では戦闘状態も戦闘乱数も変更しない。新しい状態異常の技への割り当ては行わない。


仕様の優先順は GO確定仕様 → GO正式CSV・技説明 → MHB実装 → GO暫定案。MHBのコードと参照CSVは読み取り専用で調査し、対応する挙動を geneOrderBattle の状態・イベントに移した。

## 状態管理と期間

- 個体の毒は残存ターンで管理し、当ターン末にダメージを与えた後に1減らす。締め付けの交代制限は同じ残存トークンを使う。
- 陣営フィールドと個体の一時回避率補正は、同IDにつき1件、発生・開始・排他的終了ターンを持つ。六芒星術をTに使うと特殊軽減はT+1～T+3、砂煙はT～T+3、追い風はT～T+2、回避率補正はT+1のみ。
- 実戦と予測は previewDamage → calculateDamage を共有。予測は状態を変更しない。フィールド効果は直接攻撃にのみ適用。

後続の特殊技・交代・パッシブ・AI・UIにも同じ仕様優先順を適用する。
