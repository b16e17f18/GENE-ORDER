# v0.50 未確定仕様

## AIから正式画面への接続で確認する事項

- AIが使える公開情報の範囲。現在の対面、場、公開済み状態だけで開始できる。相手の未公開技・控えを既知と仮定するか、候補シナリオとして推定するかは別に決める。プレイヤーが入力した行動は非公開。
- 同速・回避・防御・交代の候補をAIがどこまで予測するか。v0.50は公開済み技、公開予約、対面とフィールドを参照する。未知技は一般的な脅威として扱う。図鑑で固定技を公開する場合は公開範囲を切り替えられる。
- 以下の未完成技は現状の選択不可を維持すればAI開始の阻害要因にならない。有効化する場合は対応する仕様を先に確定する。

| 未完成技 | 有効化前に確認する事項 |
|---|---|
| 発電 | 持続期間、発動後に消費する火技の範囲、回避・交代・溜めとの関係 |
| 長い舌 | 持ち物の移動条件、未所持時や奪取不可時の扱い |

## 正式UI接続・バランス調整まで保留できる事項

- リバイブの直接致死限定、反撃との順序、属性無効を変化技へ広げるか。
- 技使用時効果の回避・無効時、溜め開始・解放の扱い。全身全霊と窮鼠猫噛の威力上限は現行160を維持。
- 知覚過敏・毒汗の致死被弾、軌道修正の回避成功の定義、観察眼の発動点。
- 無鉄砲の優先度閾値、最大HP基準の切り捨て、HP支払いによる戦闘不能、個体対象の変化技だけを防ぐ範囲。
- 羽音の同時登場・同時補充の発動順、異常代謝の対象状態の追加、猪突猛進の最大威力195と上限200の差。
- 同じ対面で双方が有効打を得られない長期戦の扱い、編成上限と自然HP回復、AIタイプの重みや勝率の調整。

暫定の発動順は [パッシブの仕様](passive-system.md)、技の比較と現行の対応状況は [技一覧](skill-effects.md) と [特殊技の仕様](special-skills.md) を参照。

AIのタイプ別係数、長期戦の評価と連続回復・回避の抑制、未知技・控えの公開範囲は正式画面接続以降に確認する。200ターンの制限は検証用。正式な引き分け条件は未確定。
